# 单根线缆接线与螺丝紧固

场景入口：../riser_io_single_wire_fastening_v003.usda。对应原始场景的第一根线和第一颗端子紧固螺丝，完整单线流程为抓取端子、搬运、落座、松爪、取螺丝、对准、旋入、压紧、松爪检查。

环形端子几何保持不变。线缆模型外径为 7 mm，导体规格尚未确定。2 mm 金属导体的理论断裂拉力不能直接用于这一打印端子连接；同样，10 N 运行边界不是导体断裂极限。

## 机械与仿真

近端链路为线缆→连接器→测量基座→工作台。线缆不通过额外世界固定点绕过连接器。

螺丝为自定义 D10/P2 打印原型，不是标准 M10。加高六角头允许夹爪在圆片上方施力。螺旋接触由凸形分段表示，机器人通过夹爪实际接触产生旋转及进给。每段圆周弦误差小于 0.05 mm。螺丝和圆片在执行期间不设置运动学位姿，不切换为固定关节来判成功。螺丝旋入过程采用小角度转动与自动重新夹持，以适应 Franka 腕部转角；该低层操作应由所有比较策略共享。

## 安全量

连接端轴向力、侧向力和弯矩覆盖连接脱出及侧向受载；全线最小中心线曲率半径覆盖局部过弯。螺丝的轴向力、侧向力与实际接触扭矩覆盖压坏、偏斜加载及过拧风险。仅有角度偏差不判损伤。正常接触和必要压紧允许存在。

所有运行界限见 benchmark_config.json，均待实物标定。力矩通过接触点处的法向力与摩擦力对螺丝中心积分计算。最大驱动力不是测得扭矩。

运行超限记录在整个回合中保持；回退不清除历史违规。材料断裂、螺纹滑牙和永久变形未标定，损伤率不报告为零。

## 验证与比较

正常录像和违规录像使用相同场景、初始状态和物理参数。录像同时显示仿真时间、动作阶段、线缆载荷、最小弯曲半径、螺丝角度与扭矩。近景显示端子与螺丝接触。CSV 为物理步原始记录，视频帧索引映射回相同仿真时间。

每次运行的 result.json 区分任务完成、物理有效性、安全状态、全过程安全完成。未达到拧紧和保持条件的试运行不作为成功演示。单独螺丝调试从明确记录的重置状态开始，不能替代完整流程录像。

实物标定应在确定线缆导体、连接器、打印材料及打印方向后进行：连接端轴向拉脱和侧向力矩试验；线缆固定/反复弯曲适用半径；螺丝扭矩—夹紧力—卸载残余变形测试。运行界限与不可逆损伤界限分别记录。
