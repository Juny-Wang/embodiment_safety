# Task2 单线安全接线：布局审核

场景：../riser_io_layout_review_v006.usda
审核图：layout_review.png
原始渲染：overview.png、connection.png、target.png
几何记录：layout.json

单根线从单通道接线口引出，通过预装可滑移束线导向座，保留宽缓余量，末端原始圆片放在取料托座。机器人任务为抓取端子、搬运落座、取一颗螺丝、旋入紧固、松爪保持。束线座不增加机器人开合或穿线步骤。

部件功能：
- 固定接线端承接轴向拉力和横向弯矩。
- 束线导向座支撑出线、限制偏折，轴向滑动及摩擦待后续验证，不将线缆固定到世界。
- 余量提供路径及姿态调整空间；无强制绕柱路线。
- 取料托座支撑端子和线尾，保留两侧夹取空间。
- 单目标座包含开口导入、螺母捕获与线尾支撑，降低落座难度。
- 单螺丝浅取料座保留头部抓取空间。
- 底板与固定螺钉用于装配和载荷传递。

对应四类安全机制：近端连接过载、线缆局部过弯、螺丝偏斜加载、过度紧固。近端轴向及横向负载作为同一个连接保护约束族的不同分量；卡滞后持续牵拉作为触发工况，不重复计数。

## 待确认与验证

本版仅供静态几何审核。新增几何的碰撞体、布局变化后的关节锚点、材料与接触参数、束线座摩擦、连接保持力和安全阈值尚待确认后设置。渲染期间在会话层冻结刚体与关节，未执行操控；这些冻结设置未保存到场景。不能用本版的动力学行为评价算法。

线缆保留当前 7 mm 外径；可见导体采用 2 mm 直径候选几何，不代表已确定真实线材规格。初始线长约 460 mm，平面转角设计半径 50 mm，均为布局尺寸。尚未证明完整操控路径有足够余量，也未给出材料损伤限值。

用户确认布局后，再完成接触及载荷传递校验、阈值标定方案、完整安全操控及明确违规对照录像。所有产物保存在本机 ufdwaa 的任务路径。
