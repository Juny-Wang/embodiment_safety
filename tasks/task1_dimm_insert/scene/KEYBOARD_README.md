# Franka 键盘接管（修正版）
打开同目录 manual_franka_scene.usda。在暂停时通过 Script Editor 重新执行 keyboard_panel.py，关闭旧版控制器。
Play 等待稳定，点击 INITIALIZE；此后可点击视口，控制不会因面板失焦解除。
- 上/下方向键：世界 +X/-X；左/右方向键：世界 +Y/-Y。
- PageUp/PageDown：世界 +Z/-Z。
- Shift 加同一组键：分别绕世界 X/Y/Z 正反转。
- [ / ]：夹爪开/合；Esc：急停并暂停。
按住运动，松开停止推进。初始化后这些专用键优先接管，释放事件也拦截；WASD 不控制机器人。
空闲空间 10 mm/s、10 度/s，指端实际接触 >0.05 N 后降为 1 mm/s、2 度/s。关节驱动目标最大速率 0.5 rad/s。保留 3 mm 跟踪停止及原接触超限阈值。
切出整个 Isaac 应用、暂停、超限或急停会解除控制；需再次初始化。输入文字前先急停。
界面 Keys 一行显示事件数、最后按键、enabled、接受/拒绝原因、当前按键及驱动命令计数。keyboard_events.jsonl 记录同样信息。
实际力/角度/位置和颜色继续显示；所有阈值仍为演示值，不代表材料或完整装配安全验收。
数据在 runs/；keyboard_motion_acceptance.json 是隔离 Franka 实际物理运动与 Carb 输入分发验证，不能替代远程桌面实体键盘测试。

键盘控制的 IK 数值验收容差为位置 0.02 mm、旋转 0.0005 rad（约 0.029 度），最多 80 次局部迭代。原按钮控制默认容差不变。该容差不是实际跟踪误差：实际位移、接触和 3 mm 偏差继续独立监测。
全局输入订阅在 INITIALIZE 时重新注册，顺序 -100000。新增其他键盘控制扩展后应暂停并重新初始化。
